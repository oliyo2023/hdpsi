# 商品图片上传功能使用指南

## 功能概述

本系统为商品管理提供了完整的图片上传和管理功能，支持在商品添加和编辑过程中进行图片操作。

## 主要特性

### 1. 自动SN生成
- 在商品添加页面，系统会自动生成16位唯一商品SN
- SN格式：大写字母和数字组合，确保唯一性
- 用于图片存储的标识符

### 2. 图片上传功能
- **支持格式**：JPG、PNG、GIF、WebP
- **文件大小限制**：单个文件最大10MB
- **上传方式**：
  - 单张图片上传
  - 批量图片上传（拖拽多选）
  - 点击上传区域选择文件
  - 拖拽文件到上传区域

### 3. 图片管理功能
- **图片预览**：点击图片可放大查看
- **排序调整**：拖拽图片调整显示顺序
- **图片删除**：支持单张图片删除
- **主图设置**：第一张图片自动设为商品主图

### 4. 弹窗管理界面
- 专门的图片管理弹窗
- 图片列表展示
- 批量操作支持
- 实时状态更新

## 使用流程

### 商品添加流程

1. **进入商品添加页面**
   - 导航到 "商品管理" > "添加商品"
   - 系统自动生成商品SN

2. **填写基本信息**
   - 输入商品名称、类别、品牌等基本信息
   - 可选择生成SKU

3. **上传商品图片**
   - 在 "商品图片" 区域进行图片上传
   - 支持多种上传方式
   - 实时预览上传结果

4. **图片管理**
   - 点击 "管理图片" 按钮打开管理弹窗
   - 调整图片顺序
   - 删除不需要的图片

5. **保存商品**
   - 完成所有信息填写后点击保存
   - 第一张图片自动设为主图

### 商品编辑流程

1. **进入商品编辑页面**
   - 从商品列表点击编辑按钮
   - 系统加载现有商品信息和图片

2. **修改图片**
   - 在图片上传组件中查看现有图片
   - 添加新图片或删除现有图片
   - 调整图片顺序

3. **保存更改**
   - 点击保存按钮更新商品信息
   - 图片更改实时生效

## 技术实现

### 前端组件

#### ProductImageUpload 组件
- **位置**：`/src/components/ProductImageUpload.vue`
- **功能**：图片上传、预览、管理的完整解决方案
- **属性**：
  - `product-id`：商品标识符（SN或ID）
  - `disabled`：是否禁用上传功能
- **事件**：
  - `images-updated`：图片列表更新时触发

#### 商品SN生成器
- **位置**：`/src/utils/productSNGenerator.js`
- **功能**：生成16位唯一商品序列号
- **方法**：
  - `generateProductSN()`：生成基础SN
  - `validateProductSN()`：验证SN格式
  - `formatSNDisplay()`：格式化SN显示

#### 图片服务
- **位置**：`/src/services/productImage.js`
- **功能**：图片相关API调用
- **方法**：
  - `getProductImages()`：获取图片列表
  - `uploadProductImage()`：上传单张图片
  - `batchUploadProductImages()`：批量上传
  - `updateImageSort()`：更新排序
  - `deleteProductImage()`：删除图片

### 后端API

#### 图片管理接口
- **基础路径**：`/api/v1/products/{productId}/images`
- **支持操作**：
  - GET：获取图片列表
  - POST：上传单张图片
  - POST `/batch`：批量上传
  - PUT `/{imageId}/sort`：更新排序
  - DELETE `/{imageId}`：删除图片

#### 数据存储
- **数据表**：`product_images`
- **字段**：ID、ProductID、URL、Sort、时间戳
- **索引**：ProductID、Sort、创建时间
- **文件存储**：`uploads/products/{productId}/` 目录

## 错误处理

### 常见错误及解决方案

1. **文件格式不支持**
   - 错误信息："只支持 JPG、PNG、GIF、WebP 格式的图片"
   - 解决方案：使用支持的图片格式

2. **文件过大**
   - 错误信息："图片大小不能超过 10MB"
   - 解决方案：压缩图片或使用较小的文件

3. **网络上传失败**
   - 错误信息："上传失败，请重试"
   - 解决方案：检查网络连接，重新上传

4. **商品SN未生成**
   - 错误信息："请先生成商品SN"
   - 解决方案：刷新页面或手动触发SN生成

## 最佳实践

### 图片优化建议
1. **图片尺寸**：建议使用 800x800 像素的正方形图片
2. **文件大小**：单张图片控制在 2MB 以内
3. **图片质量**：使用适中的压缩比例，平衡质量和文件大小
4. **命名规范**：使用有意义的文件名

### 操作建议
1. **批量上传**：一次性上传多张图片提高效率
2. **顺序调整**：将最重要的图片放在第一位作为主图
3. **定期清理**：删除不需要的图片释放存储空间
4. **备份重要图片**：对重要商品图片进行本地备份

# 宏店应用 Google Play 上传指南

## 🚀 准备发布到 Google Play

### 第一步：构建发布版本

#### 1. 配置正式签名证书
```bash
cd mobile/android
./generate-keystore.sh
```

输入信息示例：
- **密钥库密码**: 使用强密码（请妥善保管）
- **密钥别名**: `hongdian-release`
- **公司名称**: 宏达服装有限公司
- **部门**: IT部门
- **城市**: 您的城市
- **省份**: 您的省份
- **国家代码**: CN

#### 2. 构建AAB文件（推荐）
```bash
cd mobile
flutter build appbundle --release
```

生成文件：`build/app/outputs/bundle/release/app-release.aab`

#### 3. 或构建APK文件
```bash
flutter build apk --release
```

生成文件：`build/app/outputs/flutter-apk/app-release.apk`

### 第二步：Google Play 开发者账户

#### 1. 注册开发者账户
- 访问：https://play.google.com/console
- 使用Google账户登录
- 支付注册费：$25 USD（一次性）
- 完成身份验证

#### 2. 账户验证要求
- ✅ 有效身份证明
- ✅ 电话号码验证
- ✅ 营业执照（企业账户，可选）

### 第三步：创建应用

#### 1. 在 Google Play Console 创建新应用
1. 点击"创建应用"
2. 填写应用信息：
   - **应用名称**: 宏店
   - **默认语言**: 中文（简体）
   - **应用类型**: 应用
   - **免费或付费**: 免费

#### 2. 应用详情配置

##### 基本信息
- **应用名称**: 宏店
- **简短描述**: 宏达服装进销存管理系统移动端
- **完整描述**: 
```
宏店是宏达服装有限公司开发的专业进销存管理系统移动端应用。

主要功能：
• 商品管理：商品信息录入、查询、修改
• 库存管理：实时库存查询、库存预警
• 销售管理：销售订单处理、销售统计
• 采购管理：采购订单管理、供应商管理
• 会员管理：会员信息管理、积分管理
• 数据统计：销售报表、库存报表、财务统计

特色功能：
• 扫码功能：支持商品条码扫描
• 离线同步：支持离线操作，网络恢复后自动同步
• 多店铺支持：支持多门店管理
• 权限管理：灵活的用户权限控制

适用于服装零售、批发等行业的进销存管理需求。
```

##### 应用分类
- **类别**: 商务
- **标签**: 进销存, 库存管理, 零售管理, 服装管理

##### 联系信息
- **网站**: 您的公司网站
- **电子邮件**: 您的联系邮箱
- **电话**: 您的联系电话
- **隐私政策**: 需要提供隐私政策URL

### 第四步：准备应用资源

#### 1. 应用图标
- **尺寸**: 512x512 像素
- **格式**: PNG
- **要求**: 高质量，无透明背景

#### 2. 应用截图
需要准备以下截图：
- **手机截图**: 至少2张，最多8张
- **尺寸**: 320-3840像素（宽或高）
- **格式**: PNG或JPG
- **建议**: 展示主要功能界面

#### 3. 功能图片（可选）
- **尺寸**: 1024x500 像素
- **用途**: 在Google Play中突出显示

### 第五步：上传应用

#### 1. 上传AAB/APK文件
1. 进入"发布" → "生产"
2. 点击"创建新版本"
3. 上传 `app-release.aab` 文件
4. 填写版本说明：
```
宏店 v1.0.0 首次发布

功能特性：
• 完整的进销存管理功能
• 商品、库存、销售、采购管理
• 会员管理和数据统计
• 扫码功能支持
• 多店铺管理
• 离线同步功能

这是宏店应用的首个正式版本，为服装零售行业提供专业的移动端进销存管理解决方案。
```

#### 2. 版本信息
- **版本名称**: 1.0.0
- **版本代码**: 1
- **最低API级别**: 23 (Android 6.0)

### 第六步：内容分级

#### 1. 完成内容分级问卷
- 选择应用类别：商务应用
- 回答关于暴力、性内容等问题
- 通常商务应用会获得"适合所有人"的分级

#### 2. 目标受众
- **主要目标年龄**: 18岁以上
- **次要目标年龄**: 无

### 第七步：政策合规

#### 1. 隐私政策
创建隐私政策，包含：
- 收集的数据类型
- 数据使用方式
- 数据共享政策
- 用户权利

#### 2. 应用权限说明
解释应用请求的权限：
- **相机权限**: 用于扫描商品条码
- **存储权限**: 用于保存应用数据
- **网络权限**: 用于数据同步

### 第八步：发布流程

#### 1. 内部测试（可选）
- 邀请内部测试人员
- 验证应用功能
- 收集反馈并修复问题

#### 2. 封闭测试（推荐）
- 邀请有限用户测试
- 测试期间：建议1-2周
- 收集用户反馈

#### 3. 开放测试（可选）
- 公开测试版本
- 更大范围的用户测试

#### 4. 生产发布
- 完成所有配置
- 提交审核
- 审核通过后正式发布

### 第九步：审核和发布

#### 1. 审核时间
- 通常需要1-3个工作日
- 首次发布可能需要更长时间

#### 2. 可能的审核问题
- 应用崩溃或功能问题
- 政策违规
- 元数据不完整

#### 3. 发布后管理
- 监控应用性能
- 回复用户评论
- 定期更新应用

## 🔧 常见问题解决

### 1. 签名问题
如果遇到签名错误：
```bash
# 验证签名
jarsigner -verify -verbose -certs app-release.aab
```

### 2. 权限问题
确保在 AndroidManifest.xml 中正确声明所有权限。

### 3. 审核被拒
- 仔细阅读拒绝原因
- 修复问题后重新提交
- 必要时联系Google Play支持
